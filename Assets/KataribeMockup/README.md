# 語り部リズムゲーム：ゲーム性モックアップ（Unity 6 / 2D）

## セットアップ
1. Unity Hub で **Universal 2D** テンプレートの新規プロジェクトを作る（Unity 6）
2. `Scripts` フォルダの .cs 4つと `chart_01.txt` を `Assets` にドラッグ
3. Hierarchy で 右クリック → Create Empty（名前は `Game` など）
4. `Game` に **RhythmGame** をドラッグして付ける
5. Inspector の **Chart File** に `chart_01.txt` をドラッグ（空のままでも内蔵サンプルで動きます）
6. ▶ 再生。コントローラーを挿しておく

カメラ・線・羽ペン・メトロノームは全部スクリプトが自動で作ります。

> Input System 関連のエラーが出たら：Edit → Project Settings → Player → Other Settings →
> **Active Input Handling** を「Input System Package (New)」か「Both」に。

## 操作
| 入力 | 内容 |
|---|---|
| 左スティック Y | 黄色の羽ペンの高さ（傾き＝高さ、ニュートラルで真ん中） |
| A | タップノート／ロングノートは押しっぱなしでなぞる |
| Start | リスタート |
| キーボード | W/S（↑/↓）＝高さ、Space＝A、R＝リスタート |

## 流れ（2小節で1セット）
1. **お手本の小節**：紙は止まったまま。青の羽ペンと水色の小節線が黒い線から右へ進み、ノートを書く
2. **あなたの番**：ノートと青の羽ペンが左へ流れ、黄色が黒い線でなぞる。小節の終わりに水色の線が黒い線に重なって合流
3. 合流したらすぐ次のお手本へ

BPM120・3拍子 → 1拍0.5秒、1小節1.5秒、1セット3秒。最初に1小節のカウントイン。

## 譜面の書き方（chart_01.txt）
```
tap  1.0 0.5                        # 1拍目の後（2拍目）、高さ真ん中
long 0 0.8 | 1 0.75 | 2 0.3        # 点を通るなめらかな帯
rest                                # 空の小節
---                                 # 小節の区切り
```
- 拍は 0.0〜3.0（tap は 3.0 未満）、高さは 0.0〜1.0
- 書き間違いは Console に「何行目が変か」が出ます
- テキストを書き換えたら再生し直すだけで反映

## 判定（Inspector で調整できます）
- **タップ**：時間のずれと高さのずれの両方で判定
  - Perfect：±60ms 以内 かつ 高さ ±0.10 以内
  - Good：±130ms 以内 かつ 高さ ±0.20 以内
  - それ以外（押したが高さが違う・押さなかった）は Miss
- **ロング**：Aを押しながら高さ ±0.15 以内にいた時間の割合
  - 90%以上 Perfect／60%以上 Good／それ以下 Miss
- 判定後、ノートは色づく（思い出せた）／灰色（Miss）
- 画面上部に「早い・遅い」「高い・低い」の数値が出るので、難易度調整に使えます
- 押すタイミングが毎回ズレて感じる場合は **Input Offset Ms** で補正

## 調整しやすい値
- `Bpm` / `Beats Per Measure`：テンポと拍子
- `Measure Length`：黒い線〜水色の線の距離（ノートが流れる速さ）
- `Play Y Min / Max`：高さ0と1の位置
- `Stick Smoothing`：スティックの追従を少しなめらかに
- `Loop`：オフにすると譜面の最後で終わってリザルト表示

## ファイル
- `RhythmGame.cs`：ゲーム本体（進行・判定・表示）
- `Chart.cs`：譜面の読み込みと曲線の補間
- `Metronome.cs`：クリック音の合成とオーディオ時計での再生
- `Shapes.cs`：仮ビジュアル（線・円）
